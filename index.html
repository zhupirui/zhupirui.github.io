Claude Code 安装教程

Claude Code 是一个 AI 编程助手，装在电脑上、在终端里对话。这一页零基础手把手，教你（和同学）在 Windows 和 Mac 上装好它，照着做就行。

先搞懂两个词（30 秒）

终端 / PowerShell 是什么

就是电脑上一个「能打字、电脑会执行」的窗口。Windows 上叫 PowerShell，Mac 上叫「终端」。打开它，把命令粘进去回车，就完事。

命令是什么

就是一行字，让电脑干一件事。下面所有命令你不用懂意思，复制 → 粘贴 → 回车，即可。

Windows 安装（手把手）

给用 Windows 的同学。推荐「方法 A」，不用装别的软件，最简单。

先打开 PowerShell（就一步）

点屏幕左下角「开始」按钮 → 键盘直接打字 PowerShell → 回车。弹出一个蓝框框（或黑框框），那就是它。

A

方法 A：官方脚本（最简单，推荐）

在 PowerShell 窗口里，把下面这一行复制粘贴进去，回车：

PowerShell
irm https://claude.ai/install.ps1 | iex

这行在干嘛？就是「从网上下载官方安装脚本并运行」，它会自己装好，你等着就行。装完输入 claude 回车，出来对话界面就是成功了。

B

方法 B：npm（先装 Node）

先装一个基础软件 Node.js。用 Windows 自带的「命令行软件商店」winget，一句话搞定：

PowerShell
winget install OpenJS.NodeJS.LTS

装完 Node，电脑里就有了 npm 工具。再在 PowerShell 里运行：

PowerShell
npm install -g @anthropic-ai/claude-code

不想用 winget？也可以去 nodejs.org 下载 LTS 版，双击一路「下一步」装 Node，再回来跑上面那条 npm 命令。

Mac 安装（手把手）

给用 Mac 的人。同样两个方法，方法 A 最简单。

先打开「终端」

按 Command + 空格 搜索「终端」（Terminal），回车打开。

A

方法 A：官方脚本（最简单）

在终端里粘贴下面这行，回车，等它自己装好：

终端
curl -fsSL https://claude.ai/install.sh | bash
B

方法 B：npm（先装 Node）

先去 nodejs.org 下载 LTS 版装好 Node，然后在终端里运行：

终端
npm install -g @anthropic-ai/claude-code

（我自己这台 Mac 就是用方法 B 装的，用的 Node 版本管理工具叫 nvm，不影响结果。）

装好之后怎么用

终端 / PowerShell
claude              # 启动，进入对话
claude "你的问题"     # 一句话提问

提示：命令不认怎么办

装完后如果输入 claude 提示「找不到命令」，把 PowerShell / 终端窗口关掉重开一个再试。还不行就重跑一遍安装命令。

更新

它会自动更新。想手动更新就跑 claude update。
