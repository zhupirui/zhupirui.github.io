Claude Code 安装教程

你当初是用 npm 全局安装的。这一页汇总了这台机器的核实结果、重装步骤，以及给 Windows 用户的安装方法。

你的安装方式

以下都从本机实际核实，不是模板套话。

安装命令
npm install -g @anthropic-ai/claude-code
Node 环境
nvm 管理 · node v24.16.0
安装位置
~/.nvm/versions/node/v24.16.0/lib/node_modules/@anthropic-ai/claude-code
当前版本
2.1.331
架构
Apple Silicon（arm64，原生包 darwin-arm64）
更新方式
自动更新，走 npm-global 路径

重装教程 · 三步（Mac / Linux）

按顺序执行；第 1 步在你现有机器上已经完成了，换新机时从头做。

1

装 Node（nvm 方式）

nvm 用来管理 Node 版本，跟你现在的环境一致。

zsh
# 安装 nvm（如果还没有）
curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.40.1/install.sh | bash

# 重新加载配置
source ~/.zshrc

# 安装并启用一个 Node 版本
nvm install 24
nvm use 24
2

装 Claude Code

npm 全局安装，会自动拉取你机器架构对应的原生二进制。

zsh
npm install -g @anthropic-ai/claude-code
3

启动

先验证版本，再进入对话。

zsh
claude --version      # 验证是否装好
claude                # 进入交互对话
claude "你的问题"       # 一次性问答

三种安装方式

你选的是第二种。三种都可用，任选其一。

原生安装脚本 官方推荐

不依赖 Node，自动更新最省心。Mac / Linux 用下面这条，Windows 用 PowerShell 版（见「Windows 怎么装」一节）。

zsh
curl -fsSL https://claude.ai/install.sh | bash

npm 你的方式

前提是装了 Node。你现在这套跑得好好的，不用换。

zsh
npm install -g @anthropic-ai/claude-code

Homebrew

macOS 上装了 Homebrew 的话，一条命令也能装。

zsh
brew install --cask claude-code

Windows 怎么装

给用 Windows 的人。推荐 A 方式，不用装 Node。Windows 不用 Homebrew（那是 Mac / Linux 的）。

A

原生安装（最简单，推荐）

按 Win 键，输入 PowerShell 回车打开，粘贴运行下面这行（原生命令只在 PowerShell 里有效）：

PowerShell
irm https://claude.ai/install.ps1 | iex

装完输入 claude 即可启动。若当前窗口不认 claude，关掉窗口重开一个。

B

npm 安装（和 Mac 同一条命令）

先装 Node：去 nodejs.org 下载 LTS 版一路「下一步」，或用 winget（npm 命令在 PowerShell 和「命令提示符」里都能跑）：

PowerShell
winget install OpenJS.NodeJS.LTS

然后在 PowerShell 里运行：

PowerShell
npm install -g @anthropic-ai/claude-code

两个实用提示

PATH 依赖 nvm

因为是 npm 全局安装，claude 命令只有在 nvm 加载后才在 PATH 里。平时开终端没问题（~/.zshrc 已加载 nvm），但用 ssh 远程跑、或写脚本 / cron 调它时，可能报 command not found——先执行 source ~/.nvm/nvm.sh，或直接用完整路径 ~/.nvm/versions/node/v24.16.0/bin/claude。

更新

它会自动更新（走 npm-global）。想手动触发就跑 claude update，或重跑 npm install -g @anthropic-ai/claude-code。

换新电脑时，从头照第 2 节三步走即可。
